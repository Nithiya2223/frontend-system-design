# Bundled fonts

`SourceCodePro-Regular.ttf` and `SourceCodePro-Bold.ttf` are Source Code Pro
(Copyright Adobe), licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). They are bundled so code blocks render in the
same monospace font on every machine that runs the build.

Body text uses Noto Sans from the build machine (falls back to Helvetica/Arial).
